One island. One winner.

Every match builds a new map, so no two drops play out the same way.

Fast, punchy gunfights

Pistols, SMGs, shotguns, rifles, LMGs and snipers, each with its own ammo, recoil and fire mode.

  • Auto, semi-auto and burst weapons, plus dual pistols
  • Frag, smoke and MIRV grenades, and strobes that call in airstrikes
  • Helmets, vests and backpacks in three levels

Airdrops worth fighting over

Every time the zone starts to close, a plane drops a crate into the safe circle. Inside: the rarest guns in the game.

  • M1 Garand, AWM-S, M249 and more
  • Level-3 armor, 8x scopes and big heals
  • Don't stand underneath it when it lands

A whole island to loot

Houses, barns and warehouses sit next to a hidden bunker, a police armory, a bank vault and a walled military camp.

  • Breakable crates, furniture, windows and trees
  • Roofs fade away when you step inside
  • Scopes from 2x to 8x to spot enemies early

Built for quick matches

Jump in, play a round over lunch, and try again.

A shrinking red zone

Six phases push everyone together. Outside the circle you lose health, and it gets worse each phase.

Heal up between fights

Bandages and med kits restore health. Soda and pills fill your boost meter for regeneration and extra speed.

Play with friends

Run the included server on your computer and friends on the same network can join the same match.

Host an online match

The web version is single-player against bots. To play together, run the server with Node.js:

# get the game and start the server
git clone https://github.com/br672i-blip/ringfall
cd ringfall
npm install
npm start

Open localhost:8080 and press Play Online. Friends join at the network address the server prints.
